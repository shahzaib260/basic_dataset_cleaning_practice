# Employee Data Cleaning & Feature Engineering using Pandas

This project focuses on practicing real world data cleaning and feature engineering using Python and Pandas.

## What I worked on:

Handled missing values in multiple columns

Cleaned and standardized numeric data

Created derived columns:

GetBonus based on bonus eligibility

AgeGroup to categorize employees logically

Used .loc, conditional logic, and vectorized operations

Prepared a clean dataset ready for analysis

This project helped strengthen my understanding of data preprocessing workflows that are commonly used in data analysis tasks.
